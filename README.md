# paginas-apps

Páginas públicas (privacidad, términos, soporte e invitaciones) de las apps.

| App | Carpeta | Dirección |
|---|---|---|
| Elmora | `elmora/` | https://prinnybb.github.io/paginas-apps/elmora/ |

- `elmora/join.html` es la página de los enlaces de invitación ("Toca para unirte").
- `carecircle/` solo redirige a `elmora/` (la app se llamaba CareCircle antes).
- El original de estas páginas está en el proyecto de la app, carpeta `paginas-apps/`: cambia allá y vuelve a publicar.

Para agregar otra app: copia la carpeta `elmora/`, renómbrala, cambia los textos y agrégala a `index.html`.
